Window Trigger & Emission
open→closed→updated→final
  • open: periodic partial result every 2 s
  • closed: watermark ≥ window end
  • updated: late event corrected it
  • final: watermark ≥ end + lateness (10 s) → state dropped
→ Redis · metrics.windows · S3 archive (final)

Late & Out-of-Order Handling
On time / out of order (inside bound) → normal update
Late, within allowed lateness? Yes → update window, re-emit
Too late (all windows final) → Dead Letter Queue
Duplicate event_id → ignored
Exactly-once state after crashes (checkpoint + replay)
